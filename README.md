# Pocket Search

Rustで作る独自のWeb検索エンジン。検索語を入力し、収集した実際のページからサイトを探して、本文と掲載画像を小さな端末で読む。

Googleの検索結果や順位を複製するプロジェクトではなく、自分で集めたページを独自に検索する。検索対象と収集日時を表示し、収集していないサイトまで検索できるように見せない。

## 最初に動く部分

- Rustで実装した転置インデックスとBM25に基づく順位付け
- 英語の単語検索、日本語の文字・2文字単位の検索
- 題名の重み付け、複数語の一致、本文の短い抜粋、画像URLの保持
- JSON文書を検索して結果を返すコマンド

```sh
cargo run -- examples/documents.json 'ゲームボーイ'
cargo run -- examples/documents.json 'chromatic wifi'
cargo test
```

`examples/documents.json` は自作のテスト文と存在しない `.invalid` URLで、Webから収集したページではない。現時点ではクローラー・Web画面・画像取得・Chromatic実機との接続を実装していない。

## 構成

`公開サイト → クローラー → 本文・画像URLの抽出 → 検索インデックス → 検索API → 閲覧画面`

収集と検索はMacまたはサーバーで行い、端末は検索語を送り、結果・本文・画像を表示する。まず限定したサイトで、実際の収集と検索を確かめてから対象を増やす。Google規模のWeb全体を初期版で索引化する計画にはしない。

最初の端末候補はModRetro Chromatic。ブラウザでも動作を確認できる構成にする。本体の現在のファームウェア・Wi-Fi設定・秘密情報はこのリポジトリに含めない。

## 画面の範囲

検索窓、結果一覧、サイトの本文と画像、リンク、戻る操作。しおり・閲覧履歴・読む位置の永続保存・Codexの承認アプリは対象に含めない。検索コアも検索語や閲覧履歴を記録しない。クローラーが保存する公開ページの索引は、ユーザーの閲覧履歴とは別のデータである。

動画は後の検証項目。まず本文と静止画像を扱い、外部で低解像度の連続画像へ変換して送る方式の可否を別途確認する。動画再生やYouTubeへの対応はまだ実装していない。
