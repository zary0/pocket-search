# Pocket Search artwork

[`pocket-search-logo.png`](pocket-search-logo.png) is the project logo: a compact pixel document/search mark with the **POCKET SEARCH** wordmark. The 2172 × 724 PNG uses black on white for consistent contrast in light and dark README themes. It is documentation artwork, not a Chromatic framebuffer or firmware asset.

The PNG is the editable raster source distributed by this repository; no vector source is claimed. Project artwork uses [GPL-3.0-only](../LICENSE), consistent with the rest of the project. No ModRetro or other third-party logo is included.

## Generation record

Created on 2026-10-09 with Codex's built-in image generation tool, using a nontransparent background. The generated output was inspected for wordmark spelling and composition, then copied unchanged into this directory.
